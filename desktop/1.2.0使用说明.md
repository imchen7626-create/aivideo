# AI 短剧生产台 1.2.0 · 一句话成片

安装前退出旧版，用 `AI-Short-Drama-Studio-Setup-1.2.0.exe` 覆盖安装到原目录即可。项目与模型配置都会保留。

## 一句话出片（默认入口）

1. 打开即是“一句话成片”：输入一句故事创意（或点下面的示例），选时长、画幅、旁白音色。
2. 点“一键生成成片 ▶”（或 Ctrl+Enter）。之后全自动：写故事 → 角色 → 剧情方案 → 分镜 → 首帧 → 视频 → 旁白配音 → 字幕/标题 → 剪辑 → 成片包。
3. 完成后面板里直接：预览成片、下载 MP4、下载封面、复制发布文案（标题 + 简介 + 话题）。

“上传小说”“创意写长篇”仍在旁边的标签里，流程与 1.1.0 相同。

## 这一版改了什么

| 方面 | 变化 |
| --- | --- |
| 易用 | 一句话输入框做成首页主入口；示例创意一键填入；未配置的模型以清单提示；逐步节点、原文、角色收进“制作细节”，专业模式下自动展开 |
| 配音 | 新增阿里云百炼 Qwen3-TTS 适配。只要已配置百炼生图或视频，自动复用同一 Key 配旁白，不用再添加语音服务；12 种中文音色可选 |
| 字幕 | 字幕按标点和词语断句、逐条计时，直接烧录进画面（发抖音/视频号不会丢）；SRT/VTT 同步按句切分 |
| 标题 | 片头 2.8 秒叠加 8–14 字悬念大标题（编剧在方案里生成） |
| 发布 | 成片包新增 `发布文案.txt`、`封面.jpg`（首帧 + 标题，1080×1920）、`字幕.srt` |
| 速度 | 首帧和视频按镜头并发（默认 3 镜同时），每镜出图后立即提交视频；旁白与视频同时生成 |
| 剧本 | 方案和分镜加入竖屏短视频规则：前 3 秒钩子、每 8–12 秒信息增量、中段反转、结尾悬念；旁白模式每镜一句推进剧情的旁白，首帧构图避开字幕区 |
| 稳定 | 旁白略长于镜头时自动加速（最多 1.35 倍）而不是直接失败；并发下付费请求计数用事务原子更新，不会漏计或重复 |

## 设置建议

- 声音（高级里）默认“自动”：有语音服务就配旁白，没有就保留视频原声。
- 同时生成镜头数默认 3。如果百炼提示限流或并发超限，在“高级”里调到 1–2。
- 不想要烧录字幕或片头标题，可在主面板取消勾选；修改后成片会自动标记为需重新合成（本地处理，不产生费用）。

## 已知限制

- Qwen3-TTS 的请求协议按百炼官方文档实现，已有协议模拟测试；你的账号是否开通该模型、单价多少，以百炼控制台为准。业务空间域名不支持该路由时会自动改走北京地域官方接口。
- 字幕使用系统字体（Windows 为微软雅黑）。
- 没有内置背景音乐；多角色分别配音、口型同步仍未接入。
- 1.1.0 已合成的旧项目保持原样有效；在面板里改动字幕/标题选项后需重新合成。
